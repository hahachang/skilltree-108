# 108 課綱技能樹

把十二年國教課綱的「學習內容」當成技能點，做成可點亮、可追進度的網頁 app。
目前完成自然科學與數學，其餘四領域已完成抽取可行性的前導評估。

## 資料流

```
Downloads/*.pdf ─→ parse_curriculum.py ─→ data/raw_natural.json ─┐
                   parse_math.py      ─→ data/raw_math.json    ─┤
                                                                │
   人工標註：skills_*.json（前置）、subjects_natural.json（科目）│
             taxonomy_natural.json（表三階層）、cross_links.json │
                                                                ↓
                    build_math_skills.py ─→ data/graph_math.json
                    build_natural_skills.py ─→ data/graph_natural.json
                    build_cross_links.py ─→ data/graph_cross.json
                              （三者共用 skill_builder.py 的驗證）
                                                                ↓
                                          web/ ──build_pwa.py──→ docs/
```

## 兩份輸出

- `web/` — artifact 原始檔。`index.html` 沒有 head（由 artifact 平台包上）。
- `docs/` — 靜態網站／PWA，由 `parsers/build_pwa.py` 從 `web/` 包裝產生，
  含 manifest、圖示與 service worker，可安裝到主畫面並離線使用。
  發布步驟見 [PUBLISH.md](PUBLISH.md)。

## 執行

```bash
uv run --with pdfplumber python parsers/parse_curriculum.py '<自然領綱PDF>' data/raw_natural.json 16 58
uv run --with pdfplumber python parsers/parse_math.py '<數學領綱PDF>' 
uv run python parsers/build_taxonomy_natural.py
uv run python parsers/build_math_skills.py
uv run python parsers/build_natural_skills.py
uv run python parsers/build_cross_links.py
cp data/graph_math.json data/graph_natural.json data/graph_cross.json web/
uv run --with pillow python parsers/build_pwa.py  # web/ → docs/
python3 -m http.server 8777 --directory docs   # 本機預覽（PWA 版）
```

## 自然科的重構（2026-09）

與數學同一套模型，但有三處領域差異：

- **分支色系用七大跨科概念**（INa–INg），不是 14 個主題——主題太多、顏色分不開。
  國中以上的主題碼透過 `taxonomy_natural.json` 對回所屬跨科概念。
- **六角形（綜合應用）對應國中的 IN 碼**：那是課綱明列的「跨科目主題」，
  本質就是多科技能的匯流，跟數學的「解題」條目同性質。
- **起始年級基準改用學習階段的年級上緣**（Ⅱ→4、Ⅲ→6、Ⅳ→9、Ⅴ→12）。
- **高中必修的跨科依賴只有 8 條**，但每一條都是真的卡點：地科的大氣水平運動
  必須先有物理的牛頓運動定律、潮汐必須先有萬有引力、生物的「遺傳物質為核酸」
  必須先有化學的核酸性質。分科教學會讓這些邊隱形，重構後才看得見。

建圖邏輯已抽成 `parsers/skill_builder.py`，兩個領域共用同一套驗證
（覆蓋率、指向有效性、環路偵測、前置年級反向警示）。

## 兩份課綱的編碼讀法不同（常被問）

| | 數學 | 自然 |
|---|---|---|
| 第 1 碼 | 主題（N 數與量、S 空間與形狀…） | 科別前綴（**僅高中**：B生物/P物理/C化學/E地科）＋ 主題／次主題碼；國小是 INa–INg 跨科概念 |
| 第 2 碼 | **年級**（1–12），直接看得出來 | **學習階段**：Ⅱ＝3–4年級、Ⅲ＝5–6年級、Ⅳ＝7–9年級、Ⅴc＝高中必修、Ⅴa＝高中加深加廣選修 |
| 第 3 碼 | 流水號 | 流水號 |

`PEb-Ⅴc-4` ＝ 物理・力與運動・高中必修・第 4 條。

### 國小／國中的科目歸屬怎麼來的

課綱只在高中給了科別前綴，但國中的次主題碼**可以從高中反推**——`Da` 在高中
是 `BDa`，所以是生物。實測 38 個次主題可唯一反推，覆蓋國中 226 條中的 159 條。

反推不到的有兩類，定義在 `data/subjects_natural.json`：

- `Ma`/`Mb`/`Mc`/`Na`/`Nc`/`Ba` 在高中本來就跨多科（例如 `Ba` 同時有
  `CBa` 與 `PBa`），只能逐條判定。
- 國小的 `INa`–`INg` 是跨科概念，沒有任何機械依據，127 條全部人工標註。

結果分布：物理 202、化學 198、生物 169、地科 157、跨科 53。

**自然科無法從編碼看出確切年級**——Ⅳ 涵蓋七、八、九三個年級，課綱刻意不綁定。
因此 `build_natural_skills.py` 的 `tier` 取該階段的**年級上緣**（Ⅳ→9），
供「起始年級」基準判定使用；節點另外帶 `subject` 欄位標示科別。

## 聚焦＝重新排版，不是高亮

在 779 個節點、最寬一層 57 個（4446px）的圖上高亮一條鏈，兩端往往同時
在視窗外，等於沒有高亮。實測把單一節點的祖先＋子孫抽出來重排，寬度會
掉到整張圖的 7–22%（多數 300–1000px，一個螢幕看得完）：

| 聚焦節點 | 鏈上節點 | 最寬一層 | 寬度 |
|---|---|---|---|
| `Eb-Ⅳ-11` 加速度運動必受力 | 169 | 13 | 1014px |
| `CJd-Ⅴa-4` 酸鹼游離常數 | 97 | 9 | 702px |
| `BGa-Ⅴa-3` 遺傳訊息的複製 | 65 | 4 | 312px |
| `INa-Ⅲ-1` 粒子觀（樞紐） | 393 | 30 | 2340px |

因此點節點預設進入「只看這條鏈」，可切回「在整張圖上看」。
`layout()` 因此改成純函式（回傳 pos 表而非寫回節點），兩套座標才能並存。

**不要改用「滑鼠移到線上顯示箭頭」**：觸控裝置沒有 hover，而 1.4px 的線
在交錯密集處也點不準；而且問題本來就是另一端在畫面外，看不到那條線。

## 關鍵節點怎麼算

`skill_builder.py` 對每個技能算兩個指標：

- **reach**：它總共解鎖多少下游技能（影響範圍）。前端用它決定節點半徑
  （開平方壓縮，否則根節點會大到蓋住鄰居），所以關鍵樞紐自己會浮出來。
- **gate**：把它拿掉之後，有多少技能再也走不到。這是真正的必經關口。

前端另外即時算「現在最該學的」——在目前進度下可學的技能中，依
「學完會立刻解鎖幾個」排序。**不要用連鎖可達性計算**：解鎖規則是
「前置全部完成」，遞迴傳播的話每個節點都會得到相同答案（實測全為 0）。
改用兩個可驗證的數字：立刻解鎖數，以及下游未完成技能總數。

## 抽取踩坑（動 parsers/ 之前務必看）

1. **不要用 `pdfplumber.extract_table()`**。它依偵測到的 cell 高度裁切文字，自然領綱
   一個 cell 塞十幾條條目時，尾端條目會整條消失（實測 `INb-Ⅱ-5` 不見）。
   `pdf_columns.py` 一律只借用表格 bbox 當範圍，文字自己從 word 座標重組。
2. **一頁可能有兩個幾何不同的表格**（學習表現表尾接學習內容表頭）。只取
   `find_tables()[0]` 會讓第二個表的編碼欄與敘述欄被錯誤切割，必須逐表處理。
3. **編碼有時排在行尾**（`水可自解離產生H＋與OH－。CJd-Vc-1`）。編碼框與敘述框
   各自獨立，y 座標略有落差，依 y 分行時編碼會掉到行尾，導致該條敘述被掛到上一個
   編碼、而自己變成空字串。`fix_trailing_codes()` 專門處理這件事。
4. **階段碼混用全形羅馬數字與 ASCII**（`Ⅴc` 與 `Vc` 並存），同一節點會變成兩個 key，
   必須先正規化再入庫。
5. **跨頁續行的歸屬不能用欄位索引**，換頁時表格幾何會變、索引錯位。
   改用編碼自帶的學習階段當歸屬鍵（課綱每一欄本來就是一個學習階段）。
6. **strip_noise 必須在 clean() 之前執行**。「課題N：…」規則以 `[^\n]*`
   比對到行尾，若換行已被壓掉，整段續行會被當成課題標題刪光。
7. **整欄只有續行、沒有任何編碼的欄位不能跳過**（跨頁尾巴），
   否則那段文字會憑空消失。依表頭判斷所屬階段後接回上一條。
8. **編碼可能整欄下移一行**（編碼框垂直置中）。修正前要先做整欄型態偵測，
   逐行套用會在國中頁面的主題交界誤觸發，把下一條的開頭吃進上一條。
9. **數學公式會被 PDF 排版打散**（`A-8-1` 的乘法公式抽出來是亂的），這是 PDF 內嵌
   數學排版的本質限制，少數條目需人工補。

## 跨領域連結（自然↔數學）

課綱兩份文件互不引用，79 條邊全部是人工判定，定義在 `data/cross_links.json`，
方向一律是**數學→自然**。判準是「不會這個數學就真的算不出／看不懂那個自然
條目」，不連「用得到但不是門檻」的關係，**每一條都必須寫理由**（build 會擋）。

分布：物理 37、化學 23、地科 10、生物 6、跨科 3。
最常被需要的數學是「比與比例式」（13 條）與「比與比值」（7 條）——
高中自然的數學門檻，大宗其實是國中的比例概念，不是高階內容。

跨領域前置**同樣會擋住解鎖**，並在圖上畫成虛線輪廓，跟「卡在自然科自己的鏈」
區分開來。依賴鏈的聚焦仍只在單一領域內展開，跨領域關係以詳情面板的
「需要的數學」／「自然科哪裡會用到」雙向呈現。

`build_cross_links.py` 驗證編碼存在、不重複、附理由，並檢查數學前置是否
排在自然條目之後（那代表標錯，或課綱本身有順序衝突）。

## 驗收方式

抽取完一定要跑流水號連續性檢查：同一 `(topic_code, stage)` 的 `seq` 必須是
`1..n` 沒有缺口。有缺口就代表有條目被版面吃掉了。

## 數學的「重構」模型（2026-09 第二版）

第一版直接沿用課綱骨架：同主題按流水號串 `seq`、跨學習階段串 `stage`。
問題是那 1028 條邊全是**編號順序**，不是知識依賴——它等於宣稱「N-6-6 學完才能學
N-6-7」，但那只是印刷順序。

第二版把這兩種行政鏈整個拿掉，改成：

- **節點允許拆解**：`N-6-7 解題：速度` 混了比值、單位換算、平均速度三件事，
  拆成 `N-6-7a/b/c`。每個技能保留 `src` 指回課綱原條目，可追溯。
- **別名合併**：課綱自己標「同 S-1-1」的重複條目合併成一個技能。
- **前置＝人工標註的真實概念依賴**，定義在 `data/skills_math.json`。
  課綱原文點名的編碼（如「連結加與減的關係（R-2-4）」）另存為「延伸關聯」，
  不當前置。
- **縱軸改用 depth**（依賴圖上的最長路徑），不是年級。

結果：240 技能 / 387 前置邊 / 27 層，5 個真正的起點
（`N-1-1a`、`N-1-5`、`N-1-6`、`S-1-2`、`D-1-1`）。

`build_math_skills.py` 會強制驗證：覆蓋率（每個技能都要有 prereq 標註）、
指向有效性（前置不可指向已被拆解的母條目）、**環路偵測**。任何一項失敗直接中止。

觀察到的結構事實：幾何（S）鏈比代數（N→A）淺得多。`S-8-4 全等圖形`（八年級）
深度只有 5，而同為八年級的 `A-8-7b 配方法` 深度 22。最長鏈 27 層從小一加法
一路到高一多項式不等式，中間沒有捷徑。
